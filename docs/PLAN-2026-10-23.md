## Tasks, in order

### T1. Latency to ≤ 30 s (start now) — est. 2-3 h
Budget: turn wait 6 + STT 4-5 + classify 4 + search 2 + judge||verify 6 + publish 2 + poll 3 = ~27 s.
1. Persistent Claude CLI sessions (existing `persistent=True`): one session per role (classify, judge, verify); verify must be a separate session from judge (blind). Restart every N calls (`CLAUDE_SESSION_CHUNKS`).
2. Run judge and verify **concurrently**, then compare (replaces judge -> verify chain in `turns._judge_inner`).
3. Turn assembly: cut at sentence end after ~6 s (was 5+ up to 14 s).
4. `PLACAR_CLAIM_DEADLINE_S` 120 -> 45; web poll interval 5 s -> 2-3 s (`web/js/placar.mjs` createFeed).
5. Strip CLI flags that are not needed (`--tools ""`, `--strict-mcp-config`, `--disable-slash-commands`): ~1 s per one-shot call.
Done when: rehearsal (T5) shows median ≤ 30 s.

### T2. Live transcription with local Whisper — est. 1.5-2 h
1. Chunked live STT with `faster-whisper large-v3-turbo` int8 (`STT_PROVIDER=local`, `WHISPER_MODEL=large-v3-turbo`); measure chunk latency under load.
2. Speaker ID (ECAPA) install + measure; if too slow/heavy, fall back to alternating-slot heuristic + mediator voice only.
3. Number normalisation: spoken numbers to digits ("vinte e quatro anos" -> 24).
Done when: 10 s chunk -> text in ≤ 5 s with all other services running.

### T3. Zero wrong falso — est. 1.5 h
1. **Falso rule**: published falso requires (a) a professional fact-check rating "falso" on the same claim, or (b) official data (IBGE/BCB/gov) contradicting the number by a clear margin. Otherwise cap at `impreciso` or `sem_dados`.
2. **Qualifier preservation**: judge prompt gets the exact quote and must keep "só/nunca/recorde/maior/todos"; verifier compares quote to summary.
3. **Second check for every verdadeiro** (not only numeric); cheap because verify runs in parallel (T1.2).
4. **Human approval switch**: falso (and optionally impreciso) waits in a moderator queue; one click publishes. Default ON tonight.
Done when: replay shows 0 wrong falso on the gold items and the queue works end to end.

### T4. Coverage (only after T1-T3 are stable) — est. 1 h
Loosen `is_opinion` regex (it drops "sempre/nunca/precisa/corrup..."), raise `max_claims` 3 -> 5, review `is_duplicate`, let attack turns with a checkable fact also open a claim. Re-run replay; keep only changes that do not add wrong verdicts.

### T5. Real-time rehearsal (must happen) — est. 1.5 h
