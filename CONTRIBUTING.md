# Contribuir

Abra uma issue ou um pull request contra `main`.

- App Flutter: `flutter analyze` e `flutter test`.
- Pipeline: `python3 -m pytest` dentro de `pipeline/`.
- Site: `node --test web/test/logic.test.mjs` a partir da raiz.

Não commite segredos. Chaves ficam em `pipeline/.env`, que o git ignora.

Os dados de exemplo (`web/demo/` e as amostras do pipeline) são fictícios. O `placar.json` público em `placar-dados.zenithonacademy.com.br` pertence aos seus donos.
